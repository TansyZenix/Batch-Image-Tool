# 批量图片处理 🖼️

一个跑在本地的批量图片处理小工具。在网页上给第一张图定好裁剪范围（手机相册那种拖拽裁剪框的手感），再一键把这套参数套用到全部图片，避免一张一张重复劳动。

适用于同一批图需要同样处理的场景：给一批截图裁掉同样的边缘、把一批照片统一裁成 1:1 再压缩到指定尺寸、批量旋转方向拍反的照片等等。

![同一组裁剪参数落在不同比例的图片上](docs/batch-crop-demo.png)

## 功能

- **拖拽裁剪**：四角把手改大小、拖动框体移动位置、在空白处拖动可以直接拉一个新框；带三分线辅助构图。
- **比例锁**：自由 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16，锁定后拖拽始终保持该比例。
- **旋转与翻转**：向左转 90°、向右转 90°、水平翻转、垂直翻转。旋转时裁剪框会跟着画面一起转，框住的还是同一块内容。
- **批量套用 + 单张微调**：参数默认整批一致，点「应用到全部图片」统一下发；个别图片也能单独调整，被改过的图会在左侧胶片条上打一个点，一眼看出哪几张动过。
- **胶片条预览**：左侧每张缩略图上实时画出裁剪框的落点，导出前就能确认同一组参数在不同尺寸、不同构图的图上是不是都框对了。
- **导出设置**：JPG / PNG / WEBP，JPG 与 WEBP 可调质量；缩放支持保持裁剪后尺寸、长边限制、固定宽高三种模式。
- **批量导出**：一次打包成 ZIP 下载，内含全部处理结果和一份逐张明细的 `report.txt`。单张失败不会中断整批。

## 工作原理

裁剪框记录的是**归一化坐标**（相对旋转后画面的 0~1 比例），不是绝对像素。所以同一组参数能直接套用到尺寸各异的图片上——1600×400 和 500×500 的两张图用同一个框，各自裁出自己画面的相同比例区域。

每张图片的处理顺序固定为：

```
旋转 / 翻转  →  裁剪  →  缩放  →  写出
```

正因为是比例而不是像素，如果一批图构图差异很大（比如有的主体在中间、有的偏在角落），统一套用后需要去胶片条上逐张确认，必要时单独微调。

## 快速开始

需要 Python 3.9 及以上。

```bash
# 克隆仓库
git clone https://github.com/TansyZenix/Batch-Image-Tool.git
cd Batch-Image-Tool

# 安装依赖
pip install -r requirements.txt

# 启动
python app.py
```

然后浏览器打开 <http://127.0.0.1:5000>。

## 使用流程

1. 点右上角「选择图片」，或者把图片直接拖进页面。支持 JPG、PNG、WEBP、BMP、TIFF、GIF，可多选。
2. 在中间画面上拖动裁剪框，调整到你要的范围。需要固定比例就先点一个比例预设。
3. 需要的话再用「变换」里的按钮旋转或翻转。
4. 点「应用到全部图片」，把当前这套参数下发给整批。
5. 在左侧胶片条上逐张看一眼裁剪框的落点。哪张不合适，切过去单独微调。
6. 在「导出设置」里选好格式、质量和尺寸，点「导出全部」，完成后下载 ZIP。

## 参数说明

| 设置 | 说明 |
| --- | --- |
| 裁剪比例 | 自由时拖拽不受约束；选定比例后拖拽始终维持该比例。切换比例会把当前裁剪框调整为该比例，尽量保持原面积和中心点。 |
| 缩放 - 保持裁剪后尺寸 | 按裁剪后的原始像素输出。 |
| 缩放 - 长边限制 | 长边统一缩放到指定像素，等比缩放。**这是统一尺寸，图片小的时候也会放大。** |
| 缩放 - 固定宽高 | 直接拉伸到指定宽 × 高，比例不符时会变形。 |
| 质量 | 只对 JPG 和 WEBP 生效，PNG 为无损压缩。 |
| 应用范围 | 「应用到全部图片」下发当前参数并清空所有微调标记；「重置当前图片」把当前这张恢复成默认参数。 |

面板上的「输出尺寸」读数会按后端同样的取整方式预测结果，正常情况下和实际导出的尺寸一致。

`uploads/` 和 `outputs/` 是运行期目录，已在 `.gitignore` 中忽略，程序会自动创建。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 主页面 |
| POST | `/api/upload` | 上传一批图片，返回会话 ID、文件名和原始尺寸；同时返回被跳过的文件 |
| GET | `/api/image/<会话>/<文件名>` | 取原图，供前端绘制和裁剪预览 |
| POST | `/api/export` | 按每张图各自的参数批量处理，返回逐张结果和下载地址 |
| GET | `/api/download/<会话>` | 把处理结果打包成 ZIP 下载 |
| POST | `/api/reset/<会话>` | 清空该会话的上传与输出 |

导出请求体形如：

```json
{
  "session": "会话 ID",
  "ops": {
    "photo.jpg": {
      "crop": { "x": 0.1, "y": 0.1, "w": 0.6, "h": 0.5 },
      "rotate": 90,
      "flipH": false,
      "flipV": false
    }
  },
  "output": {
    "format": "jpg",
    "quality": 92,
    "resize": { "mode": "long_edge", "value": 1600 }
  }
}
```

## 注意事项

- **服务只监听本机** `127.0.0.1` 且没有身份验证，用的是 Flask 开发服务器，是本机自用的小工具，不要暴露到公网。
- **重新选择图片会替换当前整批**，上一批的参数不会保留。确认好再换。
- **上传的原图会临时留在 `uploads/`**，处理结果留在 `outputs/`。换批次时旧会话会被自动清掉，也可以直接删这两个目录。
- **EXIF 方向会被自动摆正**（按手机拍照的方向显示和导出），但导出的图片不再写入 EXIF 信息。
- **大图**：单张上限约 4 亿像素，单次上传上限 2 GB。
